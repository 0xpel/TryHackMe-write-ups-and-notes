# TryHackMe Write-ups & Notes

A collection of my write-ups, notes, and solutions from TryHackMe rooms as I progress
through the cybersecurity learning path toward Red Team / Penetration Testing.

## 🗺️ Learning Path
- [x] Pre-Security
- [x] Cyber Security 101
- [ ] Jr. Penetration Tester (in progress ~20%)

## 📁 Structure
- `/writeups` - Room solutions, walkthroughs, and lab exercises
- `/cheatsheets` - Quick-reference sheets (Nmap, OSINT)
- `/notes` - Concept notes

## 🔧 Topics Covered
- Networking (OSI, TCP/IP, Nmap, Wireshark)
- Reconnaissance (host discovery, port scanning, service/version detection, passive vs. active)
- Exploitation (Metasploit, EternalBlue, SMB)
- Credential Attacks (Mimikatz, Pass-the-Hash, John the Ripper)
- Cryptography (Hashing, Salting, HMAC)
- Web Application Attacks (XSS, Burp Suite, Hydra, Gobuster, SQLMap)
- Subdomain Enumeration & SSL Certificate Inspection
